# AndOfCourse

Set a subject for a conversation and start listening when you’re ready. A floating companion offers relevant explanations and can show the sources behind an answer.

[AndOfCourse at Burrito’s Labs](https://burritoslabs.com/catalogue/andofcourse/)

## Technology

Native macOS audio capture and interface, a networked model service and domain-document controls.

## Architecture

The native Mac app handles audio capture and the companion interface. A separate service handles model requests. Domain documents and optional private learning are managed through app controls.

## Development status

The current development build explores a floating companion for conversation explanations and source inspection.
